# Quickstart: working on the Claude Code module

What to run, what not to edit, and the traps this feature carries.

## Verify a change

From the repository root:

```powershell
ruff check .
ruff format --check .
pytest -q
python tools/check_blueprint_consistency.py
python tools/check_links.py
```

From `site/`:

```powershell
npm run lint
npm run typecheck
npm run test:unit
npm run build
npm run check:payload
npx playwright test
```

The `pre*` scripts regenerate site data, so the new exporter runs before build, dev, typecheck, and
unit tests without a separate step.

## Never edit these by hand

- `site/src/data/claude-code.json` — generated by `tools/export_claude_code_data.py`. Edit
  `claude-code/commands.yml` instead, or the `.claude/` files it reads.
- `site/src/data/blueprint.json`, `mock.json`, `items.json` — as established by features 001 and 002.
- Any weight, item count, or domain ordering. Domain 3 is 3.1% and two mock items because
  `blueprint.json` says so.

## The traps

**The repository's own hook will block you.** It denies any `Write` or `Bash` call whose path or
command mentions a protected ground-truth filename, and the match runs over the whole command
string — so a heredoc containing `<protected>` in prose, or a destructive command inside a Python
string literal, is refused. Both happened while this feature was specified. Write such files with
the editor tool rather than a shell heredoc, or build the string in parts. This behaviour is not a
bug to fix here; it is the worked example, and
[contracts/hook-recording.md](contracts/hook-recording.md) publishes it.

**A denial is not a failure.** The worker's `failed` message means the worker broke. A hook exiting
`2` is the hook working. The `run-hook` message keeps them apart and no caller may conflate them.

**Two end-to-end specs assert these addresses are inert.** `site/tests/e2e/reserved-routes.spec.ts`
and `reserved-extension.spec.ts` currently require the three pages to show the reserved-page text and
contain no interactive control. They are rewritten, not deleted — their route-stability assertions
are what enforce FR-050. Follow the precedent their own comments record from feature 002.

**Do not import the runtime client anywhere but the configuration page.** The terminal, the scope
exercise, and the playground never fetch Pyodide. A gate checks this against the built site.

**The hierarchy is concatenated, not overridden.** Scopes load managed policy, user, project, local,
and every file's content is present in the result. If you find yourself writing code that removes a
lower-precedence instruction, the exercise is teaching the misconception it exists to correct.

## Definition of done for a phase

The full gate set above passes, and the constitution's Principle VI holds: a phase ends where a
reviewer can inspect and commit. Delegated implementers leave work uncommitted; the orchestrator
re-runs the gates and commits.
